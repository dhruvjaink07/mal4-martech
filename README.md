# MarTech Campaign Architecture

A system architecture study for a Marketing Technology Campaign Management platform.

## Structure

| Section | Description |
|---------|-------------|
| [01 – Problem Understanding](docs/01-problem-understanding/) | Problem statement, stakeholders, functional & non-functional requirements |
| [02 – Solution Design](docs/02-solution-design/) | Overview, system context, high-level & low-level design, component responsibilities |
| [03 – Architecture Decisions](docs/03-architecture-decisions/) | Architecture Decision Records (ADRs) |
| [04 – Workflows](docs/04-workflows/) | Campaign lifecycle, approval, revision, and failure-recovery workflows |
| [05 – Diagrams](docs/05-diagrams/) | Mermaid diagrams (context, containers, state machine, sequences, deployment) |
| [06 – Data Design](docs/06-data-design/) | Domain model, database schema, event catalog |
| [07 – Quality Attributes](docs/07-quality-attributes/) | Scalability, reliability, security, observability |
| [08 – Architecture Defence](docs/08-architecture-defence/) | Trade-offs, failure scenarios, anticipated questions |
